## ✨ Overview

This project is a modern, responsive Single Page Application (SPA) built with React and Tailwind CSS, featuring smooth animations powered by Framer Motion. The site showcases our portfolio, services (including materials and terms), and provides clients with easy access to free consultations.

---

## 🛠 Tech Stack

* **Frontend:** React.js
* **Styling:** Tailwind CSS
* **Animations:** Framer Motion
* **Routing:** React Router DOM

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

You need **Node.js** (version 16 or higher) and **npm** installed on your machine.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/your-username/meena-interiors.git](https://github.com/your-username/meena-interiors.git)
    cd meena-interiors
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Ensure Asset Paths are Correct:**
    This application relies on local files (videos, images, logos) located in the `src/assets` directory. Ensure these files are present:
    * `src/assets/logo.png`
    * `src/assets/bgvideo.mp4`
    * `src/assets/before-image.PNG`
    * `src/assets/after-image.PNG`
    * `src/assets/founder.PNG`
    * **Image Folders:** (`/modularkitchen`, `/doors`, `/falls`, `/TVUNIT`, etc.)

4.  **Start the development server:**
    ```bash
    npm start
    ```
    The application should now be accessible at `http://localhost:3000` (or the port specified in your console).
